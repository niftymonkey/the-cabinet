# The solver is the difficulty instrument

An automated player that solves a generated house the way a person would ships alongside the
generator and stays in the repository permanently. It is not a fairness check that gets deleted once
it passes. It reports how many nights a house takes to crack, so difficulty is tuned by generating a
thousand houses, reading the distribution, and moving the dials.

Puzzle games are not the author's genre and personal taste is not a reliable gauge here, so
difficulty gets measured rather than argued. Every design position about how hard the game should
feel is answerable by this tool, which is what keeps those positions cheap to change.
