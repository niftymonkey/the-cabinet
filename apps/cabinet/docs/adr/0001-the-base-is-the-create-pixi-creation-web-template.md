# The base is the create-pixi creation-web template

The cabinet's base is the create-pixi `creation-web` template, generated first, with our code fitting inside it. Chosen over `bundler-vite` (near-empty, so screen navigation, resize, audio and an asset pipeline would all be hand-written) and `framework-react` (the cabinet is one canvas scene, and React around it buys nothing). The template brings screen navigation for the standing-in-front and leaned-in states, letterbox resize for phone and desktop, an audio plugin with persistent settings, a UI kit, and an AssetPack pipeline for the cabinet art. It is also the base The Hungry Grave chose, so one set of habits covers both applications.
