# The Cabinet

The multicade that holds every game Mark has built. The website is the machine: you stand in front of it, lean in to its monitor, and pick a game from the game select, which sends you to that game's own address.

This file is the vocabulary. What the cabinet is for lives in `PRODUCT.md` beside it.

## Language

### The machine

**Cabinet**: The arcade machine and the site, one thing. A multicade: one box, many games inside, pick one. _Avoid_: launcher, hub, portal, landing page.

**Multicade**: The kind of cabinet this is: a single home machine holding many games behind a game select, the kind sold for basements and game rooms today. _Avoid_: emulator box, jukebox, arcade (the venue).

**Monitor**: The cabinet's display, set into its front. It shows something while you stand in front, and the game select once you lean in. _Avoid_: screen (the create-pixi template's word for its own views, so it would mean two things in this code), display, canvas, viewport.

**Game select**: The list on the monitor you pick a game from. _Avoid_: menu, launcher, catalog, library, shelf.

### Being there

**Standing in front**: The first view: the whole cabinet in sight, with room to move left and right around it. _Avoid_: home, landing, overview, idle.

**Leaning in**: Clicking or tapping the cabinet so the monitor fills the view and the game select can be used. Leaning back out returns to standing in front. _Avoid_: zoom, zoom in, focus, open, enter.

### The games

**Game**: One self-contained application, reachable from the game select and living at its own address. Its own words live in its own `CONTEXT.md`, and none of them are borrowed here. _Avoid_: app, title, entry, item.

**Address**: The public web address a game lives at, its own deploy. Picking a game sends this tab there; the cabinet never holds the game. _Avoid_: route, link, path.
