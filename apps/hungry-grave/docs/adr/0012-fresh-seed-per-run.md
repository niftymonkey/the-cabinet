# A fresh seed per run, a pinned seed as the instrument

Every fresh run rolls a fresh seed: first play, restart, and play again each roll fresh dice, because different seeds play as meaningfully different games and that variety is a keeper. A seed in the URL pins the run in either form (`?seed=` before the hash or after the route), and pinning is the playtest instrument: identical-run comparisons live behind an explicit URL, never the default.

A run's seed stays visible in the UI, so seeds work as shareable challenges. Ruled after a silently defaulted seed made a dozen playthroughs the identical run.
