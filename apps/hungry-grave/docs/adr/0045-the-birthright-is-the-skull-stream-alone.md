# The birthright is the skull stream alone

A run starts with exactly one line, the skull stream at level 1, and ADR 0003's floor ladder strips back to that same list, so start state and floor state keep one shared rule. The first offer thereby becomes the run's first build fork, and no line but the skull stream is forced into every run, which the growing pool (ADR 0046) requires.

This supersedes the Territory seat ruled 2026-08-27 in [../design/weapon-pool-review.md](../design/weapon-pool-review.md). What stood: the shared start-and-floor rule, and ADR 0003's ladder mechanism untouched. What that ruling could not have known: no drop-choice existed, so the second seat was compensating for a roll the player could not steer, and no per-run roster vision existed for a permanent seat to fight. The cost is taken eyes-open: a thinner floor, with stripped-player recovery speed a named tape watch item ([../research/floor-ladder-precedent.md](../research/floor-ladder-precedent.md)).

Named consequences: early-wave scaling and early drop pacing become tuning work, the bot test and golden digest regenerate (regeneration commit first, ADR 0019), and game-concept.md's starting-loadout sentence needs correcting.

Ruled by Mark 2026-08-31 in the belch-thread grilling.
