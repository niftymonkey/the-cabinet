# A mob holds the template's arriving motion for a beat

A mob holds the template's arriving motion for a beat before its own movement takes over, so the placement's lesson still reads no matter which type is flying it. The beat governs movement only and never firing (ruled by Mark 2026-08-19, scoping an earlier proposal that covered both). The two collided: a type whose identity is firing the moment it enters would have had that identity delayed by a rule meant to protect a lane's readability. Scoped this way they compose: such a type arrives flying the template's shape, its tell lights during the arriving beat, and then it fires, so the player gets the same warning window as information rather than as a pause.

Extracted from Hungry Grave ADR 0016 on 2026-08-26, decision unchanged. Ruled by Mark 2026-08-19.
