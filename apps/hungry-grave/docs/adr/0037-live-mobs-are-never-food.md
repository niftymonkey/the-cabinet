# Live mobs are never food

Contact with a live mob shrinks the grave exactly as mob fire does, and only kills leave corpses, so a big grave can never pass under a wave for free. The rule is recorded because the hole-game default runs the other way, a hole eats whatever it covers, and an unopposed hole reading as shallow is the documented Donut County failure. Raised by Mark's own question and ruled with the weapon-lines resolution.

Extracted from Hungry Grave ADR 0005 on 2026-08-26, decision unchanged; Hungry Grave ADR 0016 restates it for mob types, and the game concept carries it in the run's description. Decision log entry 3.
