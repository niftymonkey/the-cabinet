# One execution authority

Every executed tick crosses one function: `executeTick(execution, command)` runs the tick and hands back the events it produced, and `advance`, the bot's policy loop and the golden scenario are loops over it. `Execution` is a plain record bundling the run with its listeners and fault handler, so observation cannot be forgotten at a call site, and listener order is array order, so the fan-out is deterministic. Reaching the simulation around the authority is a build failure rather than a convention, held by an ESLint fence on importing `step` plus a spelling test; the fence's load-bearing shape is documented beside the rule in `eslint.config.mjs`.

The decision exists because three legitimate paths reached the simulation, so a recording seam anywhere else had a hole by construction. Mark ruled that observability is treated the way testability is: when legitimate execution paths can bypass the seam, the architecture is refactored to create the correct seam rather than accepting the gap. The boundary means "this is the command the simulation is executing", not "this is where we happened to obtain a command", which is why `CommandSource`, the nearest existing seam, was rejected.

Two more alternatives were rejected: passing the listener array as a parameter to `executeTick`, `advance` and `runPolicy` (it makes the listeners optional at three call sites, and optional is how they get forgotten), and housing the authority in a new folder that may import RxJS (`src/game` and `src/dev` carry `mayImport: []`, and an invariant that must throw synchronously to fail a test cannot live behind a subscriber).

This amends Hungry Grave ADR 0013: the verification harness lives in `src/game`, not `src/dev`, and is load-bearing in the shipped game, because `executeTick` lives there and shipped `src/game` code may reach only `src/game`. Everything else in 0013 stands as written.

The always-on ruling is Hungry Grave ADR 0023, fault severity ADR 0024, the build-time gate ADR 0022, and the stage watch's home ADR 0025, all extracted from this file on 2026-08-26. Ruled by Mark across the analytics and replay grill on 2026-08-22 and the three review gates on #48; the argument is in [../design/analytics-and-replay-grill-2026-08-22.md](../design/analytics-and-replay-grill-2026-08-22.md).
