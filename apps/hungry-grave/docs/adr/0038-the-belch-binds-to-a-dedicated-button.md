# The belch binds to a dedicated button

The belch binds to a dedicated on-screen button, and never to a second pointer or to a steering key (ruled by Mark 2026-08-22). What the dedicated button buys over the second finger is that it cannot misfire: the belch is the scarcest object in the game, spendable only at exactly the moment it is worth most, and the post-Banshee wipe is the beat the whole feast set piece is built around. Cave's own mobile ports, DoDonPachi Blissful Death and Espgaluda II, ship a dedicated soft button for precisely this reason, because 1:1 touch movement means a bomb bound to a second finger competes with steering. The keyboard gets a dedicated key on the same terms; the button's placement and the key's mapping are control-design details that live with the code and the play-area design work, not here.

This supersedes the touch model that carried "every pointer past the steering one is the belch", deleted rather than left in the file as a comment when the ruling landed.

Extracted from Hungry Grave ADR 0011 on 2026-08-26, decision unchanged. Ruled by Mark 2026-08-22 in the weapon-lines dispatch.
