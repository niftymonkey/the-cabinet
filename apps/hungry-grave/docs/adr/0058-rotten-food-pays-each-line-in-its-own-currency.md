# Rotten food pays each line in its own currency

A rotten corpse buys a smaller burst, on ADR 0004's freshness curve and down to the same floor that growth and reservoir charge use, and each line that pays on a swallow scales the thing it actually pays in. The wisps pay in souls, so freshness scales the count, floored at one soul, because a bare proportional count pays nothing at level one where the flight is a single wisp and a swallow that fires nothing reads as a bug. The skull stream pays as a surge, a run of extra volleys at a shortened interval, and freshness scales how many volleys the surge pays rather than how wide it fires, because the column count is exactly what draws the line's five levels and a rotten corpse must never make a level-five stream look like a level-two one.

ADR 0004 already ruled that freshness scales every payout; what this record adds is the axis per line, without which the rule cannot be enforced or tested. A test that fails if a burst is ever paid without freshness applied is the point of naming the axis.

Ruled by Mark 2026-08-25 as the starting point, with the tuning left to the tuning pass.
