# Authored rows, not a director

The stage is a fixed authored timeline: data rows of phase-local time, template, placement, and count over a named template library, with phases chained by boundary events because a shootable boss dies when killed. Every die draws from its own named seeded stream (Slay the Spire's pattern), so a pinned seed replays exactly.

A wave director is deferred with named triggers (hand-authoring the full stage proving too slow, or replayability demanding cross-run variety), and a rate-based spawn faucet is a dont-build: in a single run a player cannot tell authored from directed, seeded comparability collapses once a director reads game state, and directors impose their own peaks against the stage's locked beats. Standing caution: performance-reading directors invite Battle Garegga's rank failure, where deliberate suicide became the optimal line.

Decision log entries 5.3, 5.4, and 5.10.
