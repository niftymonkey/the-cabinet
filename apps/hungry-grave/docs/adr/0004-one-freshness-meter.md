# One freshness meter

Bottom-edge camping is cured by a single per-corpse freshness meter, not separate decay and value systems: about ten seconds from kill to gone, scaling every payout (growth, burst, reservoir charge) down to a quarter floor, with the fill dimming as it drains and a last-chance flicker near empty.

The seconds are derived from scroll speed and the coupling is the invariant: a mid-screen kill must reach the bottom edge as a dim, nearly empty scrap, so a scroll retune retunes the meter with it. Drops never decay, so steady-bright always means treasure.
